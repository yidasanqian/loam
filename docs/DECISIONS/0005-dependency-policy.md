# 0005 — 依赖准入与许可证白名单

- **背景**：v1 需要路由、CLI 解析、交互与着色；过度引库会拖慢冷启动并扩大许可证面。
- **决策**：运行时依赖上限 5 个且必须 MIT/Apache、近半年有维护、无 postinstall；新增依赖在 DEPENDENCIES.md 记一行；CI 跑白名单检查。
- **代价**：部分能力手写（校验、outbox、标记块、输出裁剪）；升级需人工复审。
- **替代**：全手写（时间成本更高）；依赖拉满（供应链与许可证风险）。
- **何时重审**：每半年，或某依赖连续 6 个月无提交、出现 postinstall、或与 Workers runtime 不兼容。
