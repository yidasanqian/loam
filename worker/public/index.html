token 从哪里来？

本机已登录时，打开 ~/.loamrc.json 复制 token；或运行：

loam login --server https://loam.sanqian.workers.dev --name 本机名

token 只保存在这个浏览器（localStorage），请求只发往当前域名。服务端明文存储记忆，不要写入密钥。
